One single line that makes office life funny: the printer only jams on the one page that matters, five minutes before the meeting, while IT is on holiday.

> The printer only jams on the one page that matters, five minutes before the meeting, while IT is on holiday.

## How it works

`main.py` (Python 3 standard library only) writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 199 characters of UTF-8 text, a single line.

```sh
python3 main.py
```
